Both products say ECG. Only one matches how your house is billed. The meter keypad test is simple: if you always type tokens, you are prepaid. If you pay a monthly bill with no token, you are postpaid.

Payments happen on **Ewale** ([ewalepay.com](https://ewalepay.com) or **\*714\*22#**), not on this blog.

## What you need

1. Knowledge of how this house has been paying ECG.
2. The right identifier: meter number (prepaid) or account number (postpaid).

## The flow on \*714\*22#

1. Dial **\*714\*22#**.
2. Pick prepaid only for token meters.
3. Pick postpaid only for billed accounts.
4. If you are unsure, stop and check a previous receipt.

## After you pay

A wrong-flow payment is still a real payment to that product. Fixing it is a new, correct payment — plus support if you need help tracing the first one.

## If something fails

- **Lights still off after postpaid pay:** A network outage is not an empty prepaid meter. Token meters still need units; grid faults still need ECG.
- **Habit from the last house:** New house, new billing type. Confirm.

Choose the flow that matches the paper you already have at home.
