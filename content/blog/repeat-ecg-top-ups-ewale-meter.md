Households buy ECG tokens weekly. Re-typing an 11-digit meter number in the dark is how wrong meters get paid. You still cannot skip **lookup** on Ewale. You can skip **remembering**.

## Keep a local copy of the meter number

When power is on:

- Photograph the **sticker**.
- Write the number in a notebook kept near the meter.
- Save it as a phone note titled with the **registered name** from Ewale, not “house.”

Do not save it as a contact named “ECG” without the digits in the note — you will still guess.

## Every *714*22# session should still look up

Even if you type from the photo, wait for the **name**. Meters get replaced. A new meter on the same wall is a new number. Last month’s digits can be dead or belong to a returned device.

Repeat purchase is not the same as a stored card-on-file that charges silently. USSD is a new session every time. That is a feature: you see the name again.

## Amounts

Repeat buyers often type “the usual.” Tariffs change. GHS 50 may buy fewer units than last month. That is not Ewale short-changing you. Enter the cedis you can spend, then read the **units** on the SMS if they are included.

## Who in the house is allowed to pay

If three people all dial **\*714\*22#** on payday, you will get three tokens. Coordinate:

- One person pays.
- They send the **token SMS** (or enter it immediately).
- Others wait for the display to show units.

Parallel payments are valid purchases, not duplicates of one purchase.

## Web for repeats, USSD for outages

If you have data, Ewale on the web is easier for paste-from-notes. When the lights are already out and data is gone, **\*714\*22#** plus the notebook is the path.

The discipline is the same on both channels: identifier, name, amount, one PIN, one token.
