eResults looks like a government form because it is one. Complete it once, correctly.

Payments happen on **Ewale** ([ewalepay.com](https://ewalepay.com) or **\*714\*22#**), not on this blog.

## What you need

1. BECE voucher.
2. Index typed the same way twice if asked.

## The flow on \*714\*22#

1. Buy on **\*714\*22#** if needed.
2. Open [eresults.waecgh.org](https://eresults.waecgh.org/).
3. Exam type BECE. Year. Serial. PIN. Captcha.
4. Wait for the new window. Screenshot it.

## After you pay

Pop-up blockers sometimes hide the result. Allow the window instead of buying another PIN.

## If something fails

- **Blocked pop-up:** Enable pop-ups for this host and submit again with the same voucher.

Same PIN, better browser settings, no second debit.
