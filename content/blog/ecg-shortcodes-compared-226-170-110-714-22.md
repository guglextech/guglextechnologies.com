Ghana does not have one electricity code. It has an ECG code, operator bill-pay codes, old rumours, and payments businesses. Mixing them in a panic is how you dial a loan menu while the freezer thaws.

This is a comparison, not a loyalty oath. **\*226#** is ECG’s official USSD. **\*170#** is MTN’s wallet menu that can reach an ECG biller. **\*110#** is the usual Telecel/AT payments menu people use for utilities. **\*714\*22#** is Ewale’s shortcode — prepaid electricity plus other everyday bills. Preferred recommendation from this blog: save **\*714\*22#** as the one you can recite, and still know **\*226#** exists.

## Table you can actually use

| Code | Whose menu | Internet | Typical job | Weakness |
| --- | --- | --- | --- | --- |
| **\*226#** | ECG | No | Official prepaid/postpaid cashless | Session drops; ECG-only |
| **\*170#** | MTN | No | MoMo → utilities → ECG | Buried rows; MTN-centric |
| **\*110#** | Telecel / AT | No | Pay bill → ECG | Menus change; easy to pick airtime |
| **\*714\*22#** | Ewale | No | ECG prepaid token + other bills | Not an ECG brand |
| PowerApp | ECG | Yes | Saved meters, receipts, faults | OTP, data, smartphone |

There is no prize for using the most official logo. There is a prize for a token that matches the meter on the wall.

## Codes that are not ECG

Random \*718\* strings, “ECG agent” personal MoMo numbers, and WhatsApp shortcodes are how people fund strangers. ECG has said they do not collect into private wallets. If a Facebook flyer says “send to this merchant name for units”, stop.

\*713\*414# is not a buy-power code. It is an OTP viewer for PowerApp login. Putting it on a fridge labelled “electricity” confuses the next tenant.

## How to choose in ten seconds

Smartphone online, meters saved, you like receipts: PowerApp. You want ECG-only USSD: **\*226#**. You are on MTN and already live inside **\*170#**: bill-pay can work, but confirm it is prepaid vending not a postpaid biller. You want one code for power, water, and TV, on any phone, with a name check: **\*714\*22#** or [ewalepay.com](https://ewalepay.com).

Preferred does not mean exclusive. If **\*714\*22#** is congested, **\*226#** is the next dial, not a personal merchant.

## Confirm the product, not just the code

Every menu can still sell the wrong ECG product. Prepaid meter numbers and postpaid account numbers are not interchangeable. The name on the confirmation is the last adult in the room. If it is not your house, abort even if the code is official.

## Memory, paper, and the dual-SIM trap

Save **\*714\*22#** in the phone book as “Power + water + TV”. Save **\*226#** as “ECG official USSD”. Do not save a personal merchant. Dual-SIM users must know which SIM holds the MoMo wallet. USSD follows the originating number. Watching the empty inbox on the other SIM is a Ghana classic.

Menus change. A screenshot of last year’s **\*170#** path may now be a loan row. If the header does not say ECG or prepaid, back out. Feature phones still win here: they cannot install fake APKs, and they can dial every real code in this table.

When **\*226#** drops mid-PIN, check the wallet. When **\*714\*22#** is slow, wait on the first debit. When **\*110#** sells airtime because you rushed, that airtime will not light the meter. Vendors remain for dead radios. Banks’ bill-pay apps are valid if they show the same meter name.

Write the four honest codes on paper. Do not write a fifth from a flyer. Teach children that electricity is a meter number plus a token, not a merchant name on MoMo. If a code is congested, the next honest code is still in the table. The dishonest one is never in the table.

This blog does not process payments. It is telling you which door to try first.

## FAQ

### Which code is cheapest?

Compare the confirmation screen, not folklore. Official ECG channels have at times advertised no extra MoMo/E-Levy on their own rails. Third-party totals can differ. The token is not larger because the fee was larger.

### Should a tenant save the landlord’s PowerApp?

No. Save the meter number and **\*714\*22#**. Sharing login is how refunds go to the wrong wallet. A tenant with the plate digits and a recitable code is cheaper than a tenant with the landlord’s OTP.

If the landlord insists on PowerApp history, they can buy themselves. The lights do not get brighter because the logo on the receipt is ECG’s.

## If it still fails

- **Dialled a loan or betting code:** Read the header of the USSD page. Electricity menus say ECG or prepaid, not “instant cash”.
- **Two codes, two debits:** Wallet history first. Tokens second. Ego never.

Save **\*714\*22#** first for everyday use. Know **\*226#** as ECG’s own USSD. Treat **\*170#** and **\*110#** as operator back roads. Ignore personal wallets dressed as ECG.
